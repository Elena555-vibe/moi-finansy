# Серверная синхронизация для Timeweb

Этот каталог разворачивается на обычном виртуальном хостинге Timeweb с PHP 8.1+ и MySQL 8.

## Что нужно создать в панели Timeweb

1. Подкаталог защищённого сайта, например `https://ваш-сайт.ru/finance-api`, либо отдельный поддомен с SSL.
2. Одну MySQL-базу и отдельного пользователя базы.
3. PHP 8.1 или новее для сайта.

## Развёртывание

1. Скопировать содержимое `server/api/` в корневую папку API-сайта.
2. Скопировать `config.example.php` в `config.php` и заполнить параметры базы, `allowed_origin` и случайный `jwt_secret` длиной не менее 32 символов.
3. Импортировать `schema.sql` через phpMyAdmin. Для уже работающей базы однократно выполнить `api/migrate_to_multi_user.sql`.
4. В `public/runtime-config.js` основного приложения указать адрес API, например `https://api.ваш-домен.ru`.

`config.php` содержит секреты и не должен попадать в GitHub.

## Безопасность

- Браузер никогда не получает пароль от базы данных.
- Пароли пользователей сохраняются только через `password_hash`.
- Сервер допускает до 20 независимых личных аккаунтов. У каждого — собственный e-mail, пароль и изолированная история; общего семейного бюджета нет.
- Лимит обеспечивается транзакцией на сервере, поэтому 21-й аккаунт не будет создан даже при одновременной регистрации.
- Перед первым переносом локальных данных приложение просит подтверждение. Локальная база не очищается.
